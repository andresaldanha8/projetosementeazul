🔧 Configuração e Ajuda

1. Acesse o Painel Administrativo

Entre no painel administrativo do Projeto Semente Azul para gerenciar inscrições e pagamentos.

2. Gerencie Inscrições

No menu lateral, clique em "Gerenciar Inscrições" para visualizar todas as inscrições recebidas.

3. Confirme Pagamentos

Utilize a opção "Confirmar Pagamento" para registrar pagamentos recebidos.

4. Exporte os Dados

Use a opção "Exportar Excel" para baixar uma planilha com todas as inscrições.

💳 Gerenciamento de Pagamentos

Como Confirmar Pagamentos:

1. Receba o comprovante via WhatsApp ou email

2. Clique em "Confirmar Pagamento" acima

3. Preencha os dados do participante e pagamento

4. Confirme - isso criará um registro no sistema do site

Acompanhar Status:

• Inscrições: Acesse "Gerenciar Inscrições"

• Pagamentos: Acesse "Confirmar Pagamento"

• Compare os dois para ver quem pagou e quem não pagou

⚠️ Importante

As inscrições aparecem no painel administrativo assim que são realizadas pelos participantes. Certifique-se de que o site está publicado e funcionando corretamente.
